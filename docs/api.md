# amnesiac — публичный API v0.1

**Версия:** v0.1 · последнее изменение 2026-08-22: §5.2, §5.3, §5.6 под D-017/D-018/D-019, §9 расширен до **шести** отступлений (D-020), §4 — уточнение про сортировку.

Документ — source of truth по публичному контракту пакета. По разделу 9.1 регламента публичный API меняется только через него: изменение сигнатуры, состава полей модели или наблюдаемого поведения мимо `api.md` — дефект спринта независимо от качества кода.

Версия контракта: **0.1**. Дата принятия: 2026-08-21. Спринт: E01/S01.

---

## 1. Что пакет делает

Двухстадийная суммаризация новостного потока: тематические axis-саммари параллельно, затем сборка мета-нарратива над ними. Плюс чистая математика отбора документов по осям.

Пакет не трогает БД, сервис эмбеддингов, конфиги, файловую систему и переменные окружения. Не создаёт LLM-клиента, не читает ключи, не пишет результат. Получает данные аргументами, возвращает данные. Всё перечисленное — обязанность потребителя.

Пакет исполняется в цикле событий вызывающего кода и своего не создаёт (D-011).

## 2. Уровни стабильности

**Стабильно на `0.x`** — имя, сигнатура, состав полей и наблюдаемое поведение не меняются внутри мажорной ветки `0.x`. Ломающее изменение требует поднятия минорной версии и записи в этом документе.

**Unstable** — может измениться в любом релизе, включая патч. Потребитель, опирающийся на такое имя, пиннит точную версию.

Всё, что не описано в этом документе, публичным API не является — см. раздел 10.

## 3. Быстрый старт

```python
from amnesiac import Doc
from amnesiac.summarize import PromptPack, SummarizeConfig, summarize
from amnesiac.summarize.prompts import RU_MACRO_V1

result = await summarize(
    client=client,                       # AsyncOpenAI, чей — не важно
    model="deepseek/deepseek-v4-flash",
    axes={"дкп": [Doc(...), ...], "инфляция": [...]},
    prompts=RU_MACRO_V1.bind(horizon_days=14),
    limiter=limiter,                     # необязателен, см. 5.2
    config=SummarizeConfig(temperature=0.3, max_failed_axes=2),
)

result.meta            # str — мета-саммари
result.axis_summaries  # dict[str, str]
result.failed_axes     # list[str]
result.axis_errors     # dict[str, str]
result.usage           # Usage
```

## 4. `amnesiac` — корень пакета

Корневой `__init__` не реэкспортирует подсистемы (D-010). В корне доступно только то, что не тянет опциональных зависимостей.

### `Doc` — стабильно на `0.x`

```python
class Doc(BaseModel):
    model_config = ConfigDict(frozen=True, extra="forbid")

    text: str
    channel: str
    day_number: int
    doc_id: str | int | None = None
```

Единица входных данных суммаризации.

`text` — текст документа в том виде, в каком он пойдёт в промпт. Предобработка (нормализация, чистка разметки, отсев дайджестов) — на стороне потребителя, пакет текст не трогает.

`channel` — источник, попадает в строку промпта.

`day_number` — номер дня относительно начала окна. Величина производная, но она входит в рендер, поэтому является частью контракта. Считает её потребитель: он владеет `run_date` и горизонтом. Пакет использует её только для подстановки в шаблон, арифметики над ней не делает и ограничений на диапазон не накладывает. Ключом сортировки она служит в `select` (§6, `order_by`), а не в суммаризации: `summarize` порядок документов не меняет и получает их уже упорядоченными.

`doc_id` — идентификатор в терминах потребителя. Пакет его никогда не интерпретирует и не сравнивает, только протаскивает через отбор в результат для регресса и трассировки. Тип намеренно допускает и `int`, и `str`, чтобы потребитель не приводил `message_id` туда-обратно на границе.

Ограничение: `doc_id` нельзя использовать как ключ словаря на стороне потребителя без предварительного приведения к одному типу — `1` и `"1"` дадут разные ключи.

`extra="forbid"`: приложить произвольные метаданные к `Doc` нельзя. Если потребителю нужна сопутствующая информация, он держит её в собственной структуре, ключом по `doc_id`.

### Исключения — стабильно на `0.x`

В корне доступны `AmnesiacError` и `ConfigurationError`. Полная иерархия — раздел 8.

## 5. `amnesiac.summarize`

### 5.1 `summarize()` — стабильно на `0.x`

```python
async def summarize(
    *,
    client: AsyncOpenAI,
    model: str,
    axes: Mapping[str, Sequence[Doc]],
    prompts: PromptPack,
    limiter: AbstractAsyncContextManager | None = None,
    config: SummarizeConfig | None = None,
) -> SummarizeResult
```

Все аргументы keyword-only: это позволяет добавлять параметры и менять порядок, не ломая вызовы.

`client` — асинхронный клиент, совместимый с OpenAI SDK. Пакет обращается только к `client.chat.completions.create(...)`. Кто провайдер, откуда взят ключ, какой базовый URL и таймаут — не его дело.

`axes` — отображение «имя оси → документы». Порядок ключей значим: он определяет порядок блоков в мета-промпте. Ось с пустым списком документов допустима и обрабатывается как обычная — вызов к модели всё равно делается, ответ модели о нехватке контента отсекается на стадии меты правилом промпта. Пустое `axes` — `ConfigurationError`.

`prompts` — набор шаблонов, см. 5.4. Должен быть уже связан (`bind`) со всеми параметрами, которых нет в рантайме; недостающий ключ при рендере даёт `PromptRenderError`.

`limiter` — ограничитель параллелизма, любой асинхронный контекстный менеджер. Пакет делает только `async with limiter:` вокруг каждого обращения к модели. Если не передан — поднимается `asyncio.Semaphore(config.concurrency)`. Передача `limiter` вместе с явно заданным `config.concurrency` — `ConfigurationError`: это ошибка конфигурации, и мы падаем, а не выбираем молча (D-011).

`config` — значения, см. 5.3. `None` означает конфигурацию по умолчанию.

Возвращает `SummarizeResult`. Поднимает `TooManyAxisFailures`, если упавших осей больше `config.max_failed_axes`. Провайдерские исключения после исчерпания ретраев проходят наружу как есть. `asyncio.CancelledError` пробрасывается всегда.

### 5.2 Поведение — стабильно на `0.x`

**Порядок работы.** Все оси считаются параллельно под ограничителем, затем результаты собираются в мета-вызов. Мета-вызов один и идёт после всех осей.

**Ретраи.** Каждое обращение к модели — и axis, и meta — оборачивается ретраем: до `max_attempts` попыток, паузы берутся из `retry_delays` по номеру попытки, последнее значение повторяется, если попыток больше, чем пауз. Ретраятся только транзиентные отказы провайдера: `json.JSONDecodeError`, `httpx.ReadTimeout`, `httpx.RemoteProtocolError`, `openai.APIConnectionError`, `openai.APITimeoutError`. Этот список — часть контракта и в v0.1 не настраивается. Прочие исключения уходят наружу с первой попытки.

**Пустой ответ модели.** Ответ без текста (`choices[0].message.content is None`) приравнивается к отказу: на оси — к отказу оси со всеми последствиями ниже, на мете — к `SummarizeError`. Повторная попытка не делается: пустой ответ не входит в список транзиентных отказов, а вызов уже оплачен (D-017).

**Деградация при падении оси.** Ось, исчерпавшая ретраи или вернувшая пустой ответ, считается упавшей. Её имя попадает в `failed_axes`, текст ошибки — в `axis_errors`, а в `axis_summaries` вместо саммари подставляется `config.failed_axis_placeholder`. Заглушка **уходит в мета-промпт наравне с настоящими саммари** — это зафиксированное поведение, а не флаг. Если упавших осей больше `max_failed_axes`, мета-вызов не делается вовсе и поднимается `TooManyAxisFailures`.

Порог — абсолютное число упавших осей, не доля от общего количества.

**Отмена.** `asyncio.CancelledError` не глотается ни ретраем, ни логикой деградации. Общий таймаут задаёт вызывающий код: пакет не оборачивает работу в `wait_for`.

**Логирование.** Пакет пишет в `logging.getLogger("amnesiac.…")` и не настраивает хендлеры, уровни и формат. `print` не используется.

### 5.3 `SummarizeConfig` — стабильно на `0.x`

```python
class SummarizeConfig(BaseModel):
    model_config = ConfigDict(frozen=True, extra="forbid")

    temperature: float = 0.3
    concurrency: int = 5
    max_attempts: int = Field(3, ge=1)
    retry_delays: tuple[float, ...] = Field((5.0, 15.0, 45.0), min_length=1)
    max_failed_axes: int = 2
    failed_axis_placeholder: str = "(нет данных по оси из-за ошибки провайдера)"
```

`max_attempts` и `retry_delays` валидируются: ноль попыток и пустой кортеж пауз недостижимы. Без ограничений `retry_delays=()` даёт `IndexError` из внутренностей ретрая — сообщение об ошибке указывает не на причину (D-018).

Граница с аргументами `summarize()`: в конфиг попадают **значения** с осмысленным умолчанием, аргументами передаются **ресурсы сетапа** — клиент, модель, ограничитель, данные, промпты. `client` и `limiter` в конфиге отсутствуют принципиально.

`temperature` применяется к обеим стадиям одинаково. Раздельная температура для axis и meta в v0.1 не предусмотрена.

Умолчания воспроизводят поведение `blind_prophet` без изменений.

### 5.4 `PromptPack` — стабильно на `0.x`

```python
class PromptPack(BaseModel):
    model_config = ConfigDict(frozen=True, extra="forbid")

    name: str
    axis_system: str
    axis_user: str
    meta_system: str
    meta_user: str
    doc_template: str = "[день {day_number} | {channel}] {text}"
    doc_separator: str = "\n"
    axis_block_template: str = "=== Ось: {axis} ===\n\n{summary}"
    axis_block_separator: str = "\n\n"
    params: Mapping[str, Any] = {}

    def bind(self, **kwargs: Any) -> PromptPack: ...
```

Шаблоны рендерятся через `str.format`.

`doc_template`, `doc_separator`, `axis_block_template`, `axis_block_separator` вынесены в поля именно потому, что находятся под построчным регрессом: строка документа и разделитель блоков — такая же часть промпта, как и системное сообщение.

`bind(**kwargs)` возвращает **новый** пак с обновлённым `params`; исходный не меняется. Ключи, переданные в `bind`, доступны всем шаблонам.

Подстановки, которые пакет добавляет в рантайме:

| шаблон | рантайм-ключи |
|---|---|
| `axis_system` | `axis` |
| `axis_user` | `axis`, `docs` |
| `meta_system` | — |
| `meta_user` | `axis_blocks` |
| `doc_template` | `day_number`, `channel`, `text` |
| `axis_block_template` | `axis`, `summary` |

Всё остальное берётся из `params`. Отсутствие нужного ключа на момент рендера — `PromptRenderError` с указанием шаблона и имени ключа, а не голый `KeyError`.

**Паки иммутабельны по имени.** Правка текста существующего пака запрещена: новый текст — новое имя (`RU_MACRO_V2`). Иначе версия пакета перестаёт идентифицировать промпт, и построчный регресс теряет смысл.

### 5.5 `RU_MACRO_V1` — стабильно на `0.x`, текст заморожен

`amnesiac.summarize.prompts.RU_MACRO_V1` — пак, перенесённый из `blind_prophet` без изменений: русскоязычная суммаризация макроэкономического новостного потока с относительной датировкой.

Требует `bind(horizon_days=...)` перед использованием.

**Известные ограничения, унаследованные из исходного кода:**

- `meta_system` содержит литеральные «9 тематических таймлайнов» и «14-дневного периода» — это не плейсхолдеры. `bind(horizon_days=...)` на мета-промпт не влияет, и при другом горизонте или другом числе осей текст будет расходиться с фактическими данными молча. Исправление означает новый пак, а не правку этого;
- инструкции про относительную датировку прописаны под русский язык и российский макроконтекст. Для другого домена нужен свой пак.

### 5.6 `SummarizeResult` — стабильно на `0.x`

```python
class SummarizeResult(BaseModel):
    meta: str
    axis_summaries: dict[str, str]
    failed_axes: list[str]
    axis_errors: dict[str, str]
    usage: Usage
```

`meta` — итоговое мета-саммари.

`axis_summaries` — саммари по осям в порядке входного `axes`. Значения всегда `str`: пустой ответ модели по §5.2 становится отказом оси, поэтому `None` в словарь не попадает. Для упавших осей содержит `failed_axis_placeholder`, а не отсутствующий ключ: словарь всегда покрывает все запрошенные оси, и его содержимое совпадает с тем, что реально ушло в мета-промпт.

`failed_axes` — имена упавших осей. Пустой список при полном успехе.

`axis_errors` — «ось → `repr` последнего исключения». Живые объекты исключений в модели не хранятся: они не сериализуются и провоцируют удержание трейсбеков.

`usage` — агрегат по всем вызовам.

### 5.7 `Usage` — стабильно на `0.x`

```python
class Usage(BaseModel):
    prompt_tokens: int = 0
    completion_tokens: int = 0
    total_tokens: int = 0
    calls: int = 0
```

Суммируется по всем обращениям к модели, включая неудачные попытки, если провайдер вернул `usage`.

Стоимость не считается: в стандартной схеме OpenAI её нет, OpenRouter отдаёт её отдельным запросом к `/generation`, а такой запрос — сетевое обращение вне контракта пакета. Расчёт стоимости — на стороне потребителя, по токенам и собственному прайсу.

Разбивка usage по осям в v0.1 не предусмотрена.

## 6. `amnesiac.select`

### `select_by_axis()` — **unstable на весь `0.x`** (D-005)

```python
def select_by_axis(
    X: np.ndarray,
    queries: Mapping[str, np.ndarray],
    *,
    texts: Sequence[str],
    top_k: int,
    dedup_threshold: float,
    order_by: Sequence[float] | None = None,
) -> dict[str, list[int]]
```

Чистая синхронная функция. Сетевых вызовов не делает, `Doc` не знает, эмбеддинги не считает: векторы приходят предрассчитанными (D-006).

`X` — матрица `(n, d)` векторов документов. Нормировать заранее не нужно, функция работает с нормированной копией и вход не меняет.

`queries` — «ось → вектор запроса». Допускается как `(d,)`, так и `(m, d)`: несколько запросов на ось усредняются и перенормируются внутри. Усреднение оставлено в пакете сознательно — это часть математики отбора, находящейся под регрессом.

`texts` — тексты документов, в том же порядке, что строки `X`. Нужны дедупу: из пары похожих документов остаётся более короткий. Без них воспроизвести отбор нельзя.

`order_by` — ключ финальной сортировки, длиной `n`. Если задан, отобранные индексы сортируются по нему **стабильной** сортировкой поверх порядка убывания похожести. Если `None` — возвращается порядок убывания похожести после дедупа. Параметр существует именно для воспроизводимости: сортировка на стороне потребителя дала бы тот же результат только при точном совпадении стабильности и исходного порядка, и это слишком тонкое условие, чтобы держать его вне пакета.

Возвращает «ось → список индексов строк `X`». Индексы, не `Doc`: сопоставление с собственными записями делает потребитель.

При `n == 0` возвращает по пустому списку на каждую ось.

**Почему unstable.** Форма аргументов — прямой слепок текущего пайплайна. При подключении второго потребителя вероятна замена на структуру, описывающую корпус целиком, вместо трёх параллельных последовательностей, которые обязаны совпадать по длине.

## 7. Что пакет гарантирует по детерминизму

При одних и тех же входах `select_by_axis` возвращает один и тот же результат: сортировка стабильная, дедуп детерминирован, случайности нет.

`summarize` детерминизма не гарантирует и гарантировать не может — недетерминизм у провайдера. Пакет гарантирует лишь побайтовую воспроизводимость **текста промпта** при одинаковых `axes`, `prompts` и порядке ключей.

## 8. Иерархия исключений — стабильно на `0.x`

```
AmnesiacError                      # база, amnesiac
├── ConfigurationError             # amnesiac
├── PromptRenderError              # amnesiac.summarize
└── SummarizeError                 # amnesiac.summarize
    └── TooManyAxisFailures        # .failures: dict[str, str]
```

`ConfigurationError` — несогласованные аргументы: пустое `axes`, одновременно заданные `limiter` и `concurrency`, несовпадение длин `X`/`texts`/`order_by`.

`PromptRenderError` — при рендере не хватило ключа подстановки. Несёт имя шаблона и имя ключа.

`TooManyAxisFailures` — упавших осей больше `max_failed_axes`. В `failures` — «ось → `repr` исключения» по всем упавшим осям. Мета-вызов при этом не делался.

**Провайдерские исключения не оборачиваются.** Ошибки `openai` и `httpx` после исчерпания ретраев проходят наружу в исходном виде. Обоснование: провайдером владеет потребитель, подмена типа лишает его возможности разобрать причину — отличить исчерпание квоты от неверного ключа или отказа модели.

`asyncio.CancelledError` пробрасывается всегда и ни при каких условиях не превращается в отказ оси.

## 9. Отступления от кода `blind_prophet`

В v0.1 их ровно шесть; всё прочее перенесено байт-в-байт.

1. `SummarizeResult` возвращает axis-саммари и usage — сейчас они теряются внутри пайплайна.
2. `print` заменён на `logging`.
3. Ограничитель параллелизма инжектируется снаружи вместо `asyncio.Semaphore(5)`, создаваемого внутри. Умолчание сохраняет прежнее значение 5.
4. Мета-вызов обёрнут в тот же ретрай, что и axis-вызовы. В исходном коде он не защищён вообще. На успешном пути выход не меняется, поэтому регресс не затрагивается.
5. Пустой ответ модели обрабатывается явно (§5.2). Оригинал этот случай не проверяет и уводит `None` дальше по пайплайну. На успешном пути выход не меняется, поэтому регресс не затрагивается.
6. `asyncio.CancelledError`, возникшая на оси, пробрасывается наружу. Оригинал классифицирует отменённую ось как успешную — `isinstance(r, Exception)` ложно для наследника `BaseException`, — после чего объект исключения уходит в текст мета-промпта, а мета-вызов отправляется провайдеру. Порт как есть невозможен без нарушения §5.2 и §8. На успешном пути выход не меняется, поэтому регресс не затрагивается (D-020).

Валидация `SummarizeConfig` (§5.3) отступлением не считается: она отсекает состояния, недостижимые из `blind_prophet`, и на переносимом поведении не сказывается.

## 10. Что **не** является публичным API

Опираться на перечисленное потребителю нельзя; это меняется без предупреждения и без записи в этом документе.

- Любое имя, начинающееся с `_`.
- Раскладка модулей внутри подпакетов: `amnesiac.summarize.summarizer`, имена внутренних функций (`summarize_axis`, `summarize_meta`, `_call_with_retry` и подобные), их сигнатуры и факт существования. Публична только точка входа `amnesiac.summarize.summarize`.
- Точный текст промптов как объект правки. Читать `RU_MACRO_V1.axis_system` можно, рассчитывать на конкретные формулировки при разборе выхода модели — нет.
- Внутренности ретрая: число попыток по умолчанию, конкретные паузы, порядок логируемых сообщений.
- Формат строк логов и имена логгеров ниже `amnesiac`.
- Структура `axis_errors` и `TooManyAxisFailures.failures` как парсимый формат: это `repr` для человека и логов, не машинный контракт.
- Всё в `amnesiac.select` — unstable по D-005.
- `amnesiac.neuter` — в v0.1 отсутствует, планируется отдельным эпиком. Импорт этого подпакета в потребителе означает опору на несуществующий контракт.
- Транзитивные зависимости: наличие `httpx`, `openai`, `numpy` в окружении — следствие реализации, а не обещание.
