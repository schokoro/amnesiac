# История изменений

## 0.1.0 — 2026-08-23

### Добавлено

- Публичный API корня пакета: `Doc`, `AmnesiacError`, `ConfigurationError`.
- Публичный API `amnesiac.summarize`: `summarize`, `PromptPack`, `PromptRenderError`,
  `SummarizeConfig`, `SummarizeError`, `SummarizeResult`, `TooManyAxisFailures`, `Usage`;
  замороженный пак промптов
  `amnesiac.summarize.prompts.RU_MACRO_V1`.
- Публичный API `amnesiac.select`: `select_by_axis`.
- `amnesiac[select]` устанавливает NumPy; для суммаризации дополнительный extra не нужен
  (D-015).

Авторитетное описание API, сигнатур и поведения находится в [docs/api.md](docs/api.md).

### Стабильность и область релиза

- Весь `amnesiac.select` нестабилен на протяжении `0.x` (D-005) и может измениться даже в
  патч-релизе. Потребителю, который от него зависит, следует фиксировать точную версию.
- `amnesiac.neuter` отсутствует в v0.1 и запланирован отдельным эпиком.
- Пакет содержит аннотации типов и маркер PEP 561 `py.typed`, но аннотации поставляются как
  есть и не проверяются статическим анализатором: `mypy` не входит в гейты на `0.x` (D-023).

### Отступления от `blind_prophet`

Авторитетный список приведён в [§9 публичного контракта](docs/api.md#9-отступления-от-кода-blind_prophet).
В v0.1 ровно шесть отступлений, с сохранением нумерации контракта:

1. `SummarizeResult` возвращает axis-саммари и usage, которые в исходном пайплайне теряются.
2. `print` заменён на `logging`.
3. Ограничитель параллелизма инжектируется снаружи вместо создаваемого внутри
   `asyncio.Semaphore(5)`; значение по умолчанию остаётся равным 5.
4. Мета-вызов обёрнут в тот же ретрай, что и axis-вызовы; в исходном коде он не защищён.
5. Пустой ответ модели обрабатывается явно; оригинал не проверяет его и передаёт `None`
   дальше по пайплайну.
6. Возникшая на оси `asyncio.CancelledError` пробрасывается наружу; оригинал классифицирует
   отменённую ось как успешную и отправляет объект исключения в мета-промпте.
